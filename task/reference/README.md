# Исходные материалы

Проверено 19 октября 2026.

- [Актуальная папка организаторов](https://drive.google.com/drive/folders/1eUjfuovujgEoUbtotU9uRGWLo-RacY3T): подпапки «Регрессия», «Многоклассовая классификация», baseline.py и requirements.txt.
- [requirements.txt из этой папки](https://drive.google.com/file/d/1M4-df5jF4Zfni5R9_cmnTWQ1913ZlQLb/view) сохранён без изменений. Версии runtime и ограничения транзитивных пакетов опираются на него.
- [baseline.py из ранее переданных материалов](https://drive.google.com/file/d/17zkL_M4hepUf0AwyZZKSZ6Y3yRPixFjV/view) сохранён для сверки контракта; просмотренный baseline в новой папке имеет тот же интерфейс и цикл. Не импортируем его из нашего решения.

Новый список отличается от ранее исследованной ссылки: в нём явно указан langchain-openai и изменён состав HTTP-зависимостей. Наша реализация использует разрешённый openai напрямую. Указанный в baseline MCP отсутствует среди явных зависимостей; собственный tool dispatcher не требует MCP.

Эти файлы — справочные исходники организаторов. Не форматировать и не исправлять их как код проекта. Обновление источника требует повторной сверки версий и lock-файла. Полный список не устанавливается автоматически: используется подмножество, нужное выбранной архитектуре, и его зависимости.
