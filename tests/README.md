# Проверки

- `unit/`: доменные правила и сценарии с fake-портами, без сети и ML-обучения.
- `integration/`: временные файлы, реальные worker-процессы, маленькие модели, упаковка и восстановление.
- `fixtures/`: небольшие синтетические данные без конкурсных датасетов и секретов.

Тесты добавляются вместе с реализацией поведения по `docs/PLAN.md`. Этап 1: доменные инварианты и интеграционная подготовка задачи. Небольшие синтетические CSV создаются fixture-фабрикой в tmp_path; настоящие конкурсные данные в тесты не включаются. Проверяются numeric labels, multiclass, group/time, неизвестные категории/пропуски признаков и противоречия материалов.

`make test` исключает live-проверки. Будущие live-тесты помечаются `@pytest.mark.live`, требуют ключа выданной Qwen и запускаются явно через `uv run --locked pytest -m live`.
